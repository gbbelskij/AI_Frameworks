# Лабораторные работы 1–5: исследование алгоритмов машинного обучения

Репозиторий с результатами лабораторных работ №1–5 (2026–2027 учебный год).
В каждой работе исследуется один алгоритм на задачах классификации и регрессии: бейзлайн на `scikit-learn`, улучшение бейзлайна через проверку гипотез, собственная реализация алгоритма и сравнение результатов. Отдельный ноутбук сводит результаты всех алгоритмов.

| ЛР | Алгоритм | Ноутбук |
|---|---|---|

| 2 | Логистическая и линейная регрессия | [`notebooks/lab2_linear.ipynb`](notebooks/lab2_linear.ipynb) |

Каждой ячейке с кодом в ноутбуках предшествует текстовая ячейка с пояснением, что и зачем делается; после экспериментов записаны выводы.

## Данные

| Задача | Набор данных | Объекты | Признаки | Цель |
|---|---|---|---|---|
| Классификация | [Dota 2 Games Results](https://archive.ics.uci.edu/dataset/367/dota2+games+results) (UCI) | 92 650 train / 10 294 test (официальное разбиение) | сервер, режим, тип игры + 113 индикаторов героев (`1` — команда 1, `-1` — команда 2, `0` — не выбран) | победа команды 1 |
| Регрессия | [Chess (King-Rook vs. King-Pawn)](https://archive.ics.uci.edu/dataset/22/chess+king+rook+vs+king+pawn) (UCI) | 3 196 позиций, стратифицированное разбиение 80/20 | 36 экспертных булевых/категориальных признаков позиции | оценка позиции: `1.0` — белые выигрывают, `0.0` — нет |

**Практический смысл.**
* *Dota 2* — предсказание исхода матча по драфту (составу героев) до начала игры: помощники выбора героев, киберспортивная аналитика, оценка баланса матчмейкинга.
* *Шахматы KRKPA7* — обучение оценочной функции эндшпиля «король и ладья против короля и пешки на a7»: модель выдаёт непрерывную оценку шансов белых ŷ ∈ [0, 1], как оценочная функция шахматного движка. Исходная разметка бинарна (won / nowin), поэтому регрессия учит оценку вероятности выигрыша, а квадратичная ошибка совпадает с Brier score.

Архивы с данными лежат в [`data/`](data/) в исходном виде и читаются напрямую из zip.

## Метрики

* **Классификация:** ROC-AUC (основная — качество оценки вероятности победы, не зависит от порога), accuracy (классы почти сбалансированы: 52.7 / 47.3 %), F1.
* **Регрессия:** R² (основная — доля объяснённой дисперсии), RMSE (√Brier score, штрафует уверенные ошибки), MAE.

Гиперпараметры подбираются только на train с 5-кратной кросс-валидацией; test используется только для финальной оценки.

**Кратко:**
* *Dota 2* — после улучшений все алгоритмы сходятся к ROC-AUC 0.637–0.640 (разница меньше стандартной ошибки ≈0.005): потолок задачи задаётся информацией в драфте. Главный рычаг — признаки драфта (win rate, синергия и контрпики героев). Лучшая практическая модель — логистическая регрессия: формально лучшая, быстрая и интерпретируемая.
* *Шахматы* — лучшие модели — случайный лес и решающее дерево (R² ≈ 0.99, дерево — всего 46 правил); линейная модель даже с попарными взаимодействиями отстаёт (0.92).
* Собственные реализации воспроизводят качество `sklearn` и дают такой же прирост от тех же техник.

## Собственные реализации

Пакет [`mllab/`](mllab/) — общий код ноутбуков и самостоятельные реализации алгоритмов на `numpy` (от `scikit-learn` используются только базовые классы `BaseEstimator`/`*Mixin`, чтобы модели работали в `Pipeline` и `GridSearchCV`):

| Модуль | Содержимое |
|---|---|
| [`mllab/knn.py`](mllab/knn.py) | `KNNClassifier`, `KNNRegressor`: блочный расчёт расстояний (евклидово, манхэттенское, косинусное), `argpartition`, равные веса и веса 1/d |
| [`mllab/linear.py`](mllab/linear.py) | `LinearRegression` (МНК / Ridge, аналитическое решение), `LogisticRegression` (метод Ньютона с line search для L2, FISTA для L1), `ClippedRegressor` |
| [`mllab/tree.py`](mllab/tree.py) | `DecisionTreeClassifier`, `DecisionTreeRegressor`: CART с гистограммным поиском разбиений (gini / entropy / MSE), `max_depth`, `min_samples_leaf`, `max_features`, важность признаков |
| [`mllab/forest.py`](mllab/forest.py) | `RandomForestClassifier`, `RandomForestRegressor`: бэггинг собственных деревьев, случайные подпространства признаков, параллельное обучение |
| [`mllab/boosting.py`](mllab/boosting.py) | `GradientBoostingClassifier` (log-loss, шаг Ньютона в листьях), `GradientBoostingRegressor` (MSE), стохастический бустинг, staged-предсказания |
| [`mllab/features.py`](mllab/features.py) | `DotaFeatures` (кодирование мета-признаков, win rate героев, синергия и контрпики с out-of-fold оценкой), `ChessFeatures` (кодирование, попарные взаимодействия), `ImportanceWeighter` |
| [`mllab/data.py`](mllab/data.py), [`mllab/metrics.py`](mllab/metrics.py) | загрузка данных, метрики, журнал результатов, сравнение на кросс-валидации |

## Запуск

Требуется Python 3.12.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter lab notebooks/
```

Ноутбуки выполняются по порядку (ЛР 1 → 5, затем `summary.ipynb`); каждый сохраняет свои метрики в `results/labN.json`. Пересчитать всё из командной строки:

```bash
cd notebooks
for nb in lab1_knn lab2_linear lab3_decision_tree lab4_random_forest lab5_gradient_boosting summary; do
  jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=-1 "$nb.ipynb"
done
```

Все случайные процессы зафиксированы (`random_state=42`). Полный прогон занимает порядка часа на 16-ядерном CPU (основное время — подбор гиперпараметров на 92 тыс. матчей Dota 2).
